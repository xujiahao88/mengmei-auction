## 仓单折算口径（复刻 Excel 内嵌「竞拍煤计算公式」）

```
单价(USD) × 汇率 × (1+增值税13%) × (1+关税3%) + 唐山运费
        → × 水分调整 → + 灰分 → + 硫分 → + 强度 → + 挥发分 → + 地区 → + 仓储杂费
```

| 项 | 蒙5#原煤取值 | 说明 |
