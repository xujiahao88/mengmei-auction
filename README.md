- 价格按「同煤种同一计价币种」统计：ER/KH/KE = 元/吨，ETT/TT = 美元/吨；

## 异常场次剔除（源表串行 / 币种列错位兜底）

源表偶尔会把**别的煤种的价量抄到某一行**（煤种/指标列是模板、起拍价与成交量却是另一场的），在季节图上表现为单点「毛刺」。两条判据（同一煤种 + 同一矿点内）：

1. **量级**：起拍价与该矿全历史起拍中位数相差 ≥5 倍 —— 抓美元列填人民币；
2. **偏离**：按日期取前后各 5 场中位数，成交价与起拍价**同时**偏离 ±40% 以上（同组 ≥20 场才判，避免小样本误判）。

命中即整行剔除（价格、流拍率分母、挂牌/成交量均不计），清单打印在页面顶部。
