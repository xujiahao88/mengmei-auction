## 页面结构

1. **顶部**：蒙5#原煤 仓单折算表（本期 vs 上期 vs 环比）+ 结论文字
2. **图表区**：6 个煤种 × 4 个指标 = 24 张季节图（每条线一个年份）
   - **成交价 → 日度**：拍卖日取当日成交量加权均价，非拍卖日按最近成交价延续（≤15 天，且不越过数据末日）；横轴 366 格（MM-DD，含 2/29），每月 1 号一个刻度
   - **流拍率 / 竞拍量（挂牌）/ 成交量 → 周度**：ISO 周汇总，横轴 1–53 周（刻度落在每月首周）
   - 每张图下方指标条同频：日度图给「最新一场 / 上一场 / 环比 / 同比（去年最近一场）」，周度图给「本周 / 上周 / 环比 / 同比（去年同周）」

## 仓单折算口径（复刻 Excel 内嵌「竞拍煤计算公式」）

```
单价(USD) × 汇率 × (1+增值税13%) × (1+关税3%) + 唐山运费
        → × 水分调整 → + 灰分 → + 硫分 → + 强度 → + 挥发分 → + 地区 → + 仓储杂费
```

| 项 | 蒙5#原煤取值 | 说明 |
|---|---|---|
| 汇率 | 6.66 | 2026-10-30 中间价（frankfurter 6.6529 / er-api 6.6609） |
| 唐山运费 | 214.70 | 模板参数（甘其毛都→唐山），可按当期汽运价替换 |
| 水分 | ×1.00 | Mt 3% ≤ 8%，不扣重 |
| 灰分 | 0 | 原煤须洗选，按洗选精煤 A≈10.5%（标准品）计 |
| 硫分 | +100 | S 0.90%，大商所「S∈[0.70,1.30) 每降 0.01% 加 2.5 元」（01 合约前口径） |
| 强度 | 0 | G 洗选后 ≥75，达标 |
| 挥发分 | 0 | V 20~28，按标准区间内计（若按 28% 上限则 −50） |
| 地区 | −170 | 唐山 +170 折回山西基准 |
| 仓储杂费 | +30 | 模板参数 |

## 数据清理说明

- 完全重复行（同日期同矿同煤种同价同量）去重 52 条；
- 价格按「同煤种同一计价币种」统计：ER/KH/KE = 元/吨，ETT/TT = 美元/吨；
  1/3焦精煤跨 KH(元)/ETT(美元) 两种口径，统一折美元展示（÷6.66）；
- 「取消」场次不计入流拍率分母；
- 周度流拍率分母 = 该 ISO 周内该煤种全部非取消场次；单场次周只有 0% 或 100%，属真实形态（蒙5 基本每周 1 场）。
- 日度价格前值延续上限 15 天：蒙5 拍卖间隔中位数 6 天、蒙3 精煤 2 天，正常周更不会断；2024 年蒙5 仅 7 个拍卖日（源数据缺失）会留长断点，属数据缺口而非价格缺失。
